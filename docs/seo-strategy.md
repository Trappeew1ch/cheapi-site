# CheApi — SEO и контент-стратегия

Дата: 2 ноября 2026. Владелец: команда CheApi. Горизонт: 90 дней.

## 1. Задача

Приводить в CheApi разработчиков и небольшие команды, которые ищут доступ к GPT, Claude, DeepSeek и GLM из России, и доводить их до регистрации и первого пополнения.

Основные деньги приносят три сценария:

1. Разработчик подключает API к Cursor, Codex CLI, Claude Code или своему backend.
2. Команда ищет замену зарубежной карте и долларовому биллингу.
3. Пользователь сравнивает стоимость токенов и выбирает прозрачный рублёвый тариф.

SEO не должно обещать «первое место по API GPT». На старте реалистичная цель — длинный хвост с высоким интентом: настройка инструментов, стоимость токенов, выбор агрегатора, ошибки подключения.

## 2. Продукт и аудитория

**Продукт:** российский API-сервис к GPT, Claude, GLM, DeepSeek, изображениям, транскрибации и эмбеддингам. Один ключ, оплата в рублях, без подписки.

**ICP:**

- Разработчик в России, 1–20 человек в команде, использует Cursor/Codex/Claude Code или пишет backend на Python/Node.js.
- Не хочет покупать зарубежную карту, но готов платить за токены.
- Ценит прозрачную цену и возможность быстро проверить модель.
- Для юрлиц важны счёт, оферта и закрывающие документы.

**Дифференциаторы, которые можно доказывать:**

- Ставка 11,42 ₽ за 1 млн базовых токенов при пополнении 600 ₽.
- Открытая формула и коэффициент каждой модели.
- Минимальное пополнение 25 ₽.
- 5 млн токенов новым аккаунтам.
- 34 модели, а не «400+»: фокус на популярных семействах.
- Кеш-вход −60%, запрос без ответа не тарифицируется.
- Русскоязычная поддержка и российское юрлицо.

**Чего не утверждаем без доказательств:** «самая низкая цена», «лучший сервис», «99,9% SLA», количество клиентов, отзывы, сравнение с конкурентами по скорости.

## 8. Правила статьи

- Title 50–60 символов, первичный ключ ближе к началу.
- Description 140–160 символов, с обещанием конкретного результата.
- H1 один, совпадает с интентом, не дублирует title слово в слово.
- Первые 100 слов дают прямой ответ, а не историю про «быстрый мир».
- H2 сформулированы как вопросы или задачи пользователя.
- Одна статья — один кластер интента, без каннибализации.
- Таблица или код в каждой инструкции, FAQ в конце.
- CTA в середине и в конце, с конкретным действием и снятием риска.
- Дата публикации и обновления видимы.
- Автор — организация с понятной редакционной ответственностью; не выдумывать людей.
- Внутренние ссылки: 3–6 на статью, минимум одна на /pricing и одна на профильный лендинг.
- Не использовать фейковые отзывы, цифры клиентов и «самый дешёвый».

## 9. AI SEO

- `/llms.txt` описывает продукт, цены, API и ссылки.
- `/pricing.txt` даёт машиночитаемую формулу и таблицу моделей.
- Article/FAQ/Product schema на страницах.
- Короткие answer-блоки в начале H2.
- Таблицы для сравнений и цен.
- Не делать отдельный контент «для AI»: те же страницы должны быть полезны людям.
- Следить за цитированием в ChatGPT/Perplexity/Алисе вручную раз в месяц по 10 запросам.

## 10. Измерение

**Инструменты:**

- Google Search Console: показы, клики, средняя позиция, запросы, покрытие.

- Внутренние события: регистрация, создание ключа, первое пополнение.
- Rank tracking: 20–30 целевых запросов раз в неделю.

**Метрики 90 дней:**

- Доля проиндексированных публичных страниц: 100%.
- 10–15 запросов в топ-10 по длинному хвосту.
- 3+ коммерческих страницы с показами.
- Рост органических регистраций; базовая линия — 0, потому что домен ещё не запущен.
- Конверсия из статьи в регистрацию и из регистрации в пополнение.

## 13. Риски

- **Домен не запущен.** Пока cheapi.ru не резолвится, индексации нет. Это блокер номер один.
- **Тонкие теги.** В теге может быть 1 статья. Следить, чтобы у каждой темы было 2+ материала, иначе закрыть тег.
- **Каннибализация.** /api-gpt и статья про API GPT могут пересекаться. Статья — информационный интент, лендинг — коммерческий. Пересмотреть, если пойдут показы по одним запросам.
- **Юридические заглушки.** Реквизиты ООО «ЧЕАПИ» в `site.ts` — заглушки, их нельзя оставлять на проде.
- **Недостоверные обещания.** Не обещать SLA, скорость, «лучшую цену» без доказательств.
- **AI-контент без проверки.** Все конфиги и цены проверять на реальных запросах перед публикацией.

## 14. Launch checklist

1. Купить/подключить домен, настроить DNS и HTTPS.
2. Заменить реквизиты в `src/lib/site.ts`.
3. Задать `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`, `NEXT_PUBLIC_YANDEX_VERIFICATION`.
4. Подключить `CODEX_SALE_API_KEY` и ЮKassa.
5. Удалить demo/admin или сменить пароли.
6. Отправить `/sitemap.xml` в GSC и Вебмастер.
7. Проверить 200/404, canonical, robots, sitemap.
8. Прогнать Rich Results Test и PageSpeed.
9. Настроить аналитику и события.
10. Через 7 дней проверить индексацию и первые показы.
