# Контент-календарь CheApi

Период: ноябрь 2026 — январь 2027. Формат: 60% searchable, 30% comparison/decision, 10% experiments.

## Правила

- Одна статья = один основной интент и один primary keyword.
- Минимум 900 слов для инструкции, 1 200 для коммерческого разбора.
- В каждой статье: прямой ответ в первых 100 словах, таблица или код, CTA в середине и конце, FAQ, 3–6 внутренних ссылок.
- Не дублировать /codex, /claude-code и /api-gpt: статья решает проблему, лендинг продаёт доступ.
- Обновлять дату только после реальной проверки контента.

## Дистрибуция каждой статьи

1. Telegram-пост с одним конкретным выводом и ссылкой.
2. Короткий ответ на Habr/Q&A, если есть подходящий вопрос.
3. Обновить 2 старые статьи ссылкой на новую.
4. Добавить в тег и sitemap автоматически.
5. Через 2 недели проверить показы в GSC/Вебмастере и переписать title при низком CTR.
